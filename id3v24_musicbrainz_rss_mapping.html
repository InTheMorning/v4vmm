Native ID3v2.4 frame map, organized into 8 groups, with MusicIndex-oriented policy notes.

Canonical IDs

Store MusicBrainz IDs plus feed GUID and track/item GUID so apps can query MusicBrainz, Podcast Index, and MusicIndex using file metadata alone.

People / credits

11

 

Preferred native ID frame

Use UFID when you can provide a stable owner namespace; use TXXX for readable parallel mirrors and for metadata without a native frame.

Descriptive / technical / rights text

MusicIndex supersedence

When musicindex.org parses publisher, release_artist, and release with assurance, prefer those canonical normalized values over duplicated RSS text mirrors.

RSS projection rule

Mirror RSS / Podcast Namespace fields into native ID3 frames only when the semantic fit is clear; otherwise keep them in TXXX/WXXX or outside the file.
